# 🀄 Multiplayer Tile Game (Rummikub-like)

A real-time multiplayer board game inspired by **Rummikub**, featuring drag & drop gameplay, combination splitting, and live updates via WebSockets.

## ✨ Features

- Multiplayer lobby with automatic start
- Drag & drop tiles
- Split combinations dynamically
- Real-time updates via WebSockets
- Turn-based gameplay
- Backend-validated game logic

## 🏗️ Tech Stack

**Backend**
- Go
- WebSockets

**Frontend**
- React
- TypeScript
- Tailwind CSS
- lucide-react

## 🚀 Getting Started

### Backend Only
```bash
npm run start-backend
```

### Frontend
```bash
npm run start-frontend
```

### All at Once
```bash
npm run dev
```

### Make it public to play with your friends (with ngrok)
```bash
npm run prod
```

Open http://localhost:5173
